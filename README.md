# HEXAI

Interface pessoal de IA para Vercel, inspirada no visual enviado.

## Variáveis na Vercel

- `APP_PASSWORD`: senha para entrar no painel
- `OPENROUTER_API_KEY`: chave do OpenRouter
- `OPENROUTER_MODEL`: opcional. Pode deixar `openrouter/free`

## Deploy

Importe o repositório na Vercel e configure as variáveis acima.
